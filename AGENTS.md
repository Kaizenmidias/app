# Interface guidelines

- Consult `docs/DESIGN_SYSTEM.md` for every new Parceiros Kaizen interface.
- Reuse `public/design-system/tokens.css` and approved component patterns.
- Do not introduce new colors, fonts, buttons, or visual patterns without a justified need and explicit approval.
- Preserve consistency, responsiveness, accessibility, and security between screens.
- Do not modify the original scraper layout or assets.
- Any change to the design system requires explicit approval.
- Do not visually alter existing screens without a specific request.
